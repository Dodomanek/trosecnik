# TROSEČNÍK 3.0 – Vercel balíček

Nahraj obsah tohoto balíčku na Vercel jako statický projekt. `index.html` je v kořeni a hra nevyžaduje build krok.

Obsahuje survival upgrade s první/třetí osobou, kácením palem, výdrží sekery, jeskyněmi, divočáky, nočními hrozbami, morálkou, novými surovinami a dovednostmi.
