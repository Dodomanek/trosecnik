# Trosečník 3D 3.1 – Survival Expedition

Tato větev je připravená pro nasazení na Vercel z přesného balíčku:

`TROSECNIK_3D_3_1_SURVIVAL_EXPEDITION_VERCEL (1).zip`

## Vercel
- Build command: `npm run build`
- Output directory: `dist`
- Build skript rozbalí zdrojový ZIP beze změny do `dist/`

Větev je oddělená od `main`, takže další vývoj 3.1 nepoškodí ostatní verze.
